# Incorporated skills

Besides its core skills, this fork of Superpowers bundles 316 skills incorporated from other open-source projects. They live in `skills/` exactly like the core skills, so Claude Code, Codex, Cursor, Gemini, OpenCode, Pi, Kimi, Hermes, Muse and the other supported harnesses discover them the same way.

## Conventions

- **Names** carry the source project as a prefix (`autogpt-`, `dify-`, `ruflo-`, `anythingllm-`, `copilotkit-`), so they cannot collide with core skills or with each other. Names that already start with the project name keep it (`ruflo-status`, `copilotkit-cli`).
- **Frontmatter** `name` is set to the folder name. Descriptions and all other fields are unchanged.
- **Bodies** are unchanged except for a one-line provenance comment under the frontmatter and the reference and path fixes listed for each source below.
- **Supporting files** (scripts, references, assets, evals, license files) are copied alongside each skill.
- **Licenses**: each source's license is in [`licenses/`](licenses/). Per-skill license files are kept in the skill folders.

## ruflo

The ruflo/claude-flow toolkit: swarm and hive-mind orchestration, SPARC, AgentDB and ReasoningBank memory, GitHub automation, V3 implementation guides, and all ruflo plugin skills (ADR, DDD, cost tracking, browser automation, federation, security, testgen, workflows, and more), plus ruflo's agent-persona skills.

**License:** MIT, Copyright (c) 2024-2026 ruvnet.

- Sources: the root `SKILL.md` (as `ruflo`), `.claude/skills/*`, `.agents/skills/*`, `v3/@claude-flow/cli/.claude/skills/*`, `v3/@claude-flow/codex/.agents/skills/*`, `v3/@claude-flow/browser/skills/*`, `ruflo/src/ruvocal/.claude/skills/*`, and `plugins/*/skills/*`.
- ruflo keeps several copies of many skills. One copy per name was kept, in this order of preference: the copy `ruflo init` ships (`v3/@claude-flow/cli/.claude/skills`), then `.claude/skills`, then the browser package, then `.agents/skills`, then the condensed Codex templates in `v3/@claude-flow/codex/.agents/skills`.
- The `.agents/skills` copies of Claude skills were produced by a converter that rewrote every `/word` as `$word` (`</details>` → `<$details>`, `import('./x')` → `import('.$x')`). Where a Claude copy exists it was used instead. The `agent-*` skills exist only in that converted form, so they were rebuilt from the uncorrupted agent definitions in `.claude/agents/` that the converter started from (current versions), keeping ruflo's wrapper: the skill's own name and description, followed by the agent definition.
- `.claude/skills/dual-mode/` holds three skills as loose files (`dual-spawn.md`, `dual-coordinate.md`, `dual-collect.md`); each became its own skill folder.
- Title-case names (for example `Pair Programming`) became folder names. Two descriptions needed YAML fixes: `harness-threat-model`'s was quoted, because YAML parsers rejected it. `harness-security-bench`'s became a block scalar, because an unquoted ` #` made YAML parsers silently cut it off at "(PR". References of the form "`x` skill" and `/ruflo-goals:dossier-collect` point at the new names. `npx ruflo ...`/`skill run ...` CLI commands are unchanged.
- `memory-management` and `security-audit` listed their bundled scripts as `.agents/scripts/*.sh`, a folder ruflo does not have; the tables now point at the skill's own `scripts/`. `.claude/skills/dual-mode/README.md`, which only indexed the three dual-mode skills, was not copied.
- Relative links into the rest of ruflo's repository are now GitHub URLs pinned to the imported commit when the target exists there. Links between skills point at the new folders. Links that were already broken upstream are unchanged.
- 38 plugin skills (ADR, cost-tracker, metaharness, DeepSeek, and a few more) run scripts from ruflo's own repository, such as `node plugins/ruflo-cost-tracker/scripts/budget.mjs`, and some need its `v3/` workspace. Those commands only work inside a ruflo checkout; the commands are unchanged.
- Most of these skills drive the ruflo CLI (`npx ruflo`, `npx @claude-flow/cli@latest`) or the ruflo MCP server (`mcp__claude-flow__*`, `mcp__plugin_ruflo-core_ruflo__*`); install ruflo for them to do anything.
- 148 of these skills declare `allowed-tools`. Claude Code runs the listed tools without asking during the turn that invokes the skill, and 115 of those lists include unrestricted `Bash`. They are kept as ruflo wrote them.

**License:** MIT, Copyright (c) Mintplex Labs Inc.

- AnythingLLM does not ship `SKILL.md` files: its agent skills are server-side tool plugins in `server/utils/agents/aibitat/plugins/`. Each of the 13 skills listed in AnythingLLM's agent-skill settings became a `SKILL.md` built from that plugin's source: its tool descriptions, parameters, limits, and safety rules. Steps that AnythingLLM runs on its own server are mapped to the tools the agent already has.
- These are adaptations, not copies; each skill's provenance comment names the plugin it was built from.
